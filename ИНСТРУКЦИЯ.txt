ГОТОВО ДЛЯ PHP-ХОСТИНГА
Получатель: Alexander_zaytcev@mail.ru

1. В панели хостинга включите PHP 8.0 или новее.
2. Распакуйте СОДЕРЖИМОЕ архива в папку сайта (обычно public_html или www).
   index.html должен оказаться прямо в этой папке, а не во вложенной quiz-hosting.
   Если там уже есть другой сайт, используйте отдельную папку/поддомен.
   Если открывается старый index.php — измените стартовый файл в панели на index.html.
3. Откройте сайт и отправьте свою тестовую заявку.
4. Проверьте почту получателя, включая папку «Спам».

Получатель уже указан в api/config.php. Все фото включены.
Внешние библиотеки не нужны. На статическом хостинге без PHP отправка не работает.

ПОЧТА
Используется штатная функция PHP mail(). Хостинг должен разрешать и обслуживать
отправку писем. По умолчанию отправитель — no-reply@домен-сайта.
Если хостинг требует реальный ящик, укажите его в sender в api/config.php
и настройте почту домена в панели хостинга. SMTP-пароль от получателя не нужен.
Сам факт приёма письма сервером не гарантирует доставку во входящие.
Если mail() не настроена, письмо не придёт, но заявка будет сохранена.

СОХРАНЕНИЕ
Папка api/private должна быть доступна для записи пользователю PHP.
Не ставьте права 777. Если нет доступа — используйте панель/поддержку хостинга.
Заявки сохраняются в api/private в файлах с ID и расширением .php.
Открывайте их только через файловый менеджер хостинга: после первой защитной
строки находится JSON с телефоном, именем, ответами и статусом письма.
accepted_by_mail_server — письмо передано почтовому серверу.
mail_failed — отправка не удалась. not_configured — адрес отправителя не определён.
Автоматической повторной отправки писем нет.
Файлы заявок защищены от просмотра через браузер обработкой PHP и .htaccess.

ПЕРЕД ПУБЛИКАЦИЕЙ
В policy.html находится краткий текст по публичным названию и телефону компании;
замените его действующей политикой с полными реквизитами и условиями обработки.
Вход через Яндекс ID в самостоятельной копии не подключён.
Экран после отправки создан отдельно: чужую заявку в оригинале не отправляли.

ПРОВЕРКА СБОРКИ
JavaScript проверен на синтаксис; предыдущий Node-обработчик проверен локально.
PHP в среде сборки отсутствует, поэтому PHP-вариант и доставку письма нужно
проверить тестовой заявкой на вашем хостинге.
